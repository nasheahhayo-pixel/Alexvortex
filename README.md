# Alexvortex

Una pequeña página personal de música ("Rincón Musical") con imágenes, un widget de hora local, una breve explicación de los elementos musicales y un video.

> Nota: La versión anterior del README contenía el HTML completo. He movido ese HTML a `index.html` y he agregado un directorio `assets/` para las imágenes y el video.

## Demo
- Abre `index.html` localmente en tu navegador.
- O ejecuta un servidor simple:
  - Python 3: `python -m http.server 8000` y visita `http://localhost:8000`.

## Qué cambié en esta rama
- index.html — HTML limpio y semántico con meta viewport y accesibilidad básica.
- styles.css — estilos básicos para mejorar apariencia y legibilidad.
- assets/ — carpeta creada para imágenes y video (placeholders por ahora).
- README.md — este archivo (mejorado).
- .gitattributes — recomendado para rastrear mp4 con Git LFS (no obligatorio).

## Siguientes pasos (por ti o puedo hacerlo)
- Reemplaza los archivos en `assets/` por las versiones originales (Tempo.jpg, im.01.jpg, Relief.mp4). Si Relief.mp4 es mayor de 100 MB, usa Git LFS.
- Opcional: habilitar GitHub Pages en Settings → Pages para servir el sitio.
