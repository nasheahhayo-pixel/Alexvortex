# Assets

This folder holds media used by the site. Currently there are placeholder files. Replace them with your real media files:

- Tempo.jpg
- im.01.jpg
- Relief.mp4

If any media (especially Relief.mp4) is larger than 100 MB, consider using Git LFS:

1. Install Git LFS: `git lfs install`
2. Track mp4 files: `git lfs track "*.mp4"`
3. Commit the .gitattributes and push the media.
